# M10: Version 1.0

## Outcome

Release a stable, documented API backed by reproducible compatibility,
security, coverage, and performance evidence.

## Deliverables

- [x] Public API and exception hierarchy freeze.
- [x] Complete user guide and API reference.
- [x] Public API design review with text/HTML signature parity evidence.
- [x] Task-oriented documentation structure and generated API pages.
- [x] Documentation review with content ownership and navigation decisions.
- [ ] GitHub Pages deployment succeeds from the release commit.
- [x] Migration guide for Go template users and pre-1.0 Python import users.
- [x] Compatibility report with measured case counts.
- [x] Security model and reporting policy.
- [x] Performance report with Go and Python-ecosystem comparisons.
- [x] Packaging, release, and support policy for gotpl and its required
  workspace packages.
- [ ] Signed and reproducible release artifacts where practical.

## Acceptance Gates

- [ ] All earlier required milestone gates pass on the release commit.
- [x] Repository coverage reaches at least 98% statement and 95% branch.
- [x] No release-blocking conformance or security test is skipped.
- [x] All known differences are public and classified.
- [ ] Wheels install and tests pass across the supported platform matrix.
- [x] The release candidate passes the full benchmark suite without an
  unaccepted regression.
- [x] Runtime installation and execution require no Go toolchain or compiler.
- [x] The documentation site builds with strict warnings and links in local CI.
- [ ] Required extracted distributions are published, installable together,
  and covered by coordinated compatibility and rollback procedures.

## Release Claim

The phrase "fully compatible" may be used only for a reference area whose
required conformance suite passes completely. Other areas must use precise,
measured language.
